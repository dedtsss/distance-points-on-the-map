# DarkCat Photo — аудит утверждённой графики, Stage A

Канонический исходник: `icon-selected-original.png`, 1254×1254 PNG, SHA-256
`0f21b1535d5ae97567365bc64439c1c28c55138eb72b88d51a0f4060542946f7`.
Это достаточный растровый master для текущих статических Android-ресурсов: его разрешение больше всех размещённых изображений знака. Исходник не изменён. Сохранены чёрный кот с синими глазами, розовые уши, стопка фотографий, тёмная округлая основа и палитра. Встроенного мелкого wordmark нет. Векторная перерисовка и AI-редизайн не выполнялись.

Воспроизводимость: `node scripts/launcher-icons.mjs` генерирует каждый размер непосредственно из исходника, одним масштабированием с high-quality smoothing; `--check` проверяет SHA-256 исходника, размеры и каждый пиксель ресурсов. Промежуточные low-res производные не используются.

- Все 20 ранее одобренных launcher/round/adaptive PNG сохранены попиксельно: legacy 48/72/96/144/192 px; adaptive foreground/background 108/162/216/324/432 px. Foreground размещён как 66dp изображение по центру 108dp слоя; фон взят из самого master. Общие круглые и squircle-маски проверяются на сохранение кота и фотографий; только внешняя декоративная основа может попадать под маску. Скрипт проверки сохраняет прежние точные преобразования.
- Найденные 11 splash PNG были стандартным знаком Capacitor на белом фоне. Теперь это прямые производные утверждённого master на тёмном `#10151c`, в прежних portrait/landscape размерах, со знаком 176dp (до 704px на xxxhdpi).
- Для Android SplashScreen API добавлены пять плотностей прозрачного 288dp холста с исходным знаком 128dp по центру. Весь квадрат знака помещается в гарантированную окружность 192dp: `128 × √2 < 192`, без обрезки ушей/фотографий. Максимум 512px изображения знака; master не увеличивается. Прозрачен внешний холст, а собственный утверждённый фон иллюстрации сохранён.
- Launch theme использует тёмный фон, `splash_mark` и переход в текущую тему приложения. Отображаемое имя приложения — DarkCat Photo; package остаётся `app.darkfoto.mvp`.

Представительные bitmap-ресурсы визуально проверены в portrait xhdpi и launcher-масках. Android resource compilation и точная регенерация проверяются обычным CI. Физический cold/warm start, OEM launcher/masks и читаемость при конкретных настройках дисплея остаются проверкой владельца на устройстве. Для будущего изменения самого master требуется утверждение владельца; текущий checkpoint сохраняет утверждённую иллюстрацию.

Требования платформы: [Adaptive icons](https://developer.android.com/develop/ui/compose/system/icon_design_adaptive), [Splash screen dimensions](https://developer.android.com/develop/ui/views/launch/splash-screen#splash_screen_dimensions).
