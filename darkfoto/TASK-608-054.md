## Product behavior

- All confident valid GPS is equivalent for identity: EXIF, OCR, both index modes, unrelated indexes and days between captures. Automatic grouping searches every existing group in stable photo order. Default same-point radius is **4 m**. Every member pair must fit the radius, preventing bridge chaining even when the representative changes. Exact duplicates stay with their first copy; otherwise the nearest compatible representative wins, with stable point order breaking ties. Invalid/low-confidence coordinates remain separate.
- Compact **⚙ / Настройки** stores independent app preferences: radius **0.5–10 m, step 0.5**, minimum point distance **5–100 m, step 1**. Defaults are **4 / 25 m**. Settings survive restart and explicit job reset. Saving radius affects later automatic grouping/additions without changing existing membership or owner choices.
- Minimum-distance changes immediately reclassify existing logical points without regrouping. The fixed **2 m** accepted tolerance remains: hard conflict below `minimum − 2`, warning/Main from that boundary to below minimum, compliant at minimum. UI warnings show measured neighbor distance and configured minimum; map nearby selection and local export use the same preference. Manual status overrides retain existing semantics.
- **«Перегруппировать текущую сессию»** saves the displayed preferences, then requires a destructive confirmation. Cancel leaves existing membership intact. Confirm rebuilds from recognized evidence, including excluded/removed photos, without OCR, original-file reads or GPS replacement. It preserves selected files, metadata fields and index mode, rebuilds membership/representative/manual choices and statuses, invalidates prior publication, and immediately flushes the repaired native recovery snapshot. A subsequent launch restores it exactly without regrouping.
- The 0.5.3 native recovery, manual statuses and visual destination picker remain in the regression suite. No dependency, backend, upload/privacy, native plugin, access, signing or release-path change.
