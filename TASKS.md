# Задачи проекта

## Ближайшие задачи

### 1. Изучить удаление EXIF без пересоздания изображения

Текущий способ очистки metadata:

- фото читается;
- GPS извлекается заранее;
- изображение отрисовывается на canvas;
- создаётся новая JPEG-копия без EXIF/GPS/device/timestamp metadata.

Проблема текущего способа:

- изображение пересжимается;
- возможно ухудшение качества;
- возможна потеря мелких деталей;
- на больших фото может быть высокая нагрузка на память телефона;
- нужно отдельно контролировать orientation.

Нужно изучить более правильный вариант:

- удалять EXIF/metadata из JPEG без перерисовки изображения;
- сохранять исходное качество изображения;
- не менять пиксели фото;
- сохранять корректную ориентацию;
- работать в браузере без backend, если возможно.

Проверить варианты:

- браузерные библиотеки для удаления APP1/EXIF-сегментов из JPEG;
- возможность использовать wasm-решения;
- возможность отдельного backend/proxy для обработки metadata;
- ограничения проекта ExifCleaner: подходит ли он как библиотека или это только desktop/Node/Electron-инструмент.

Критерий принятия решения:

- если можно стабильно удалить metadata в браузере без потери качества — заменить canvas-очистку;
- если нельзя — оставить canvas как безопасный fallback и явно писать в интерфейсе, что создаётся новая JPEG-копия.

### 2. Проверить рабочий фотохостинг без API-ключей

Текущий статус:

- Catbox напрямую нестабилен;
- UMBPhotos и NinjaBox руками работают, но прямой POST из GitHub Pages даёт Failed to fetch;
- вероятно нужен прокси из-за CORS/Cloudflare.

Следующий шаг:

- решить, нужен ли Cloudflare Worker/VPS proxy для UMBPhotos/NinjaBox;
- отдельно проверить Catbox после правок интерфейса и GPS.

- упростить технический текст про очистку metadata;
- позже добавить копирование ссылок и экспорт TXT.
